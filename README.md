# Sorting Visualizer

A sorting visualizer built using HTML, CSS, and JavaScript. It allows users to visualize the process of sorting various arrays using different algorithms such as Bubble Sort, Insertion Sort, Selection Sort, Merge Sort, and Quick Sort.

## Features
- Visualize sorting of arrays in real-time.
- Includes popular sorting algorithms:
  - **Bubble Sort**
  - **Insertion Sort**
  - **Selection Sort**
  - **Merge Sort**
  - **Quick Sort**
- Interactive UI for adjusting array size and sorting speed.
- Step-by-step visualization of each sorting algorithm.
